❓ Hilfe & Tipps

Wie spiele ich?

  • Wähl unten links über "Du sprichst als" einen Helden aus.
  • Beschreibe was du tust (z.B. "Ich öffne die Tür leise") und drück Enter.
  • Der DM beschreibt was passiert.
  • ⏹ Stop: Während der DM antwortet, klick den roten Senden-Button um abzubrechen.

Würfeln

  • Klick einen Würfel-Button rechts → Ergebnis wird ins Eingabefeld eingefügt → Enter zum Senden.
  • Manchmal verlangt der DM einen Wurf — dann erscheint ein 🎲-Chip unter seiner Nachricht. Klick draufrum den Wurf automatisch zu schicken.

Spiel-Markierungen (DM-Tags)

Der DM kann diese Tags benutzen — sie verändern das Spiel automatisch:

  • [ITEM: X] → X kommt ins Inventar
  • [VERBRAUCHT: X] oder [VERLOREN: X] → X wird entfernt
  • [SCHADEN: Name -W] → Held verliert W HP
  • [HEILUNG: Name +W] → Held bekommt W HP
  • [WÜRFEL: W20 Grund] → fragt nach Wurf

Charakter-Werte

  • STR Stärke · DEX Geschicklichkeit · CON Konstitution
  • INT Intelligenz · WIS Weisheit · CHA Charisma
  • Höhere Werte = besser. 10 ist Durchschnitt, 18 ist heroisch.

Speichern & Fortsetzen

  • Wird automatisch gespeichert (kleines "💾 Gespeichert" unten rechts).
  • Tab schließen + zurückkommen → Spiel geht weiter wo du aufgehört hast.
  • 🆕 Neue Runde: löscht den Spielstand und startet neu.

DM-Modus (oben rechts neben den Steuerungen)

  • Cloud · Pollinations (…) → der DM antwortet via Internet-Dienst (gratis, anonym, kein Account nötig).
  • Lokal · <modell> → LM Studio läuft auf deinem Rechner — alles offline, deine Daten bleiben lokal.
  • DM offline → kein Internet UND kein lokales LM Studio. → Internet checken oder LM Studio starten.
