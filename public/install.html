Häufige Fragen

Ich finde keinen Download-Knopf, was tun?

Falls Windows/Mac/Linux noch "Coming Soon" zeigt: Die Native-App-Versionen werden gerade von GitHub Actions gebaut, das dauert beim ersten Mal ~10 Minuten nach jedem Tag-Push. Schau bei GitHub Releases direkt vorbei.

In der Zwischenzeit: Im Browser spielen oder die PWA-Version als App installieren — die ist jederzeit verfügbar.

📱 Android: PWA-Installation Schritt für Schritt
  1. Öffne valdermoor.vercel.app in Chrome.
  2. Drei-Punkte-Menü ⋮ oben rechts → "App installieren".
  3. Bestätigen → App-Icon erscheint im Home-Screen.
📲 iPhone / iPad: PWA-Installation Schritt für Schritt
  1. Öffne valdermoor.vercel.app in Safari (geht nicht in Chrome auf iOS).
  2. Tippe unten auf Teilen-Button (Quadrat mit Pfeil).
  3. Wähle "Zum Home-Bildschirm" → "Hinzufügen".
Ist das eine "echte" App oder nur ein Browser-Lesezeichen?

Windows / Mac / Linux Native-Apps (.exe / .dmg / .AppImage): Echte Software, läuft als eigener Prozess, eigenes Fenster, im Startmenü/Dock — wie jede andere Desktop-App. Basiert auf Electron.

PWA (Android/iOS Add-to-Home-Screen): Nicht ganz "nativ" — aber eigenes Fenster ohne Browser-UI, eigenes Icon, separater Prozess. Für 99% der User nicht von einer nativen App zu unterscheiden.

Kostet das was?

Nope. Komplett kostenlos. Open Source, kein Tracking, kein Account, kein In-App-Kauf. Made with ⚔ by Ben.
