Wenn dein Browser PWAs unterstützt (Chrome, Edge, Brave, Samsung Internet), erscheint hier ein direkter Installier-Knopf.

📱 Android-App installieren
  1. Öffne valdermoor.vercel.app in Chrome auf deinem Android-Handy.
  2. Tippe oben rechts auf das Drei-Punkte-Menü ⋮.
  3. Wähle "App installieren" oder "Zum Startbildschirm hinzufügen".
  4. Bestätige mit "Installieren".
  5. Fertig — die App liegt jetzt auf deinem Home-Screen wie jede andere App.

💡 Funktioniert auch in Edge, Firefox, Samsung Internet — überall heißt's ähnlich.

📲 iPhone / iPad installieren
  1. Öffne valdermoor.vercel.app in Safari (nicht Chrome — das geht auf iOS nicht).
  2. Tippe unten auf den Teilen-Button (Quadrat mit Pfeil nach oben).
  3. Scroll im Menü runter und tippe "Zum Home-Bildschirm".
  4. Tippe oben rechts auf "Hinzufügen".
  5. Fertig — App-Symbol ist auf deinem Home-Screen.
💻 Desktop installieren (Windows · Mac · Linux)
  1. Öffne valdermoor.vercel.app in Chrome oder Edge.
  2. In der Adressleiste rechts erscheint ein kleines Install-Symbol ⊕ (oder ein Computer-mit-Pfeil-Symbol).
  3. Klick darauf → "Installieren".
  4. Alternativ: Drei-Punkte-Menü ⋮ → "Apps" → "Diese Seite installieren".
  5. Die App startet im eigenen Fenster, hat ein Icon im Startmenü/Dock und läuft auch wenn der Browser zu ist.

💡 Safari auf Mac unterstützt PWA-Installation seit macOS Sonoma — über das Datei-Menü → "Zum Dock hinzufügen".
